## Editing and deploying

All content lives in [`gitprofile.config.ts`](./gitprofile.config.ts). Every push to `main` rebuilds and deploys the site to GitHub Pages through [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml).

```shell
npm install
npm run dev     # http://localhost:5173/portfolio/
npm run build
```

The profile picture and bio shown on the site come from the GitHub profile, so changing the GitHub avatar updates the site automatically.
